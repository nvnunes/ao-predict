# Prediction API

Use `ao_predict.prediction` to load a validated model package, predict physical
target values from direct or named NumPy inputs, and calculate generic
complete-population relative-error measurements.

The same public names are re-exported from the `ao_predict` package root. Raw
PyTorch models, weights, metadata mappings, standardization tensors, and
package helpers are private implementation details.

::: ao_predict.prediction
